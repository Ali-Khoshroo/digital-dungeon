## Found a mistake?

There are probably typos, broken links, or technical inaccuracies hiding somewhere in here. If you spot one, I'd genuinely appreciate you letting me know — the easiest way is to open an [Issue](../../issues) on this repo:

1. Click the **Issues** tab at the top of this repository
2. Click **New issue**
3. Briefly describe what's wrong and, if you can, which post/page it's on

No need to be formal about it — a one-line "hey, typo in your XSS post" is more than enough.
